8. Show the result copy and explain that it is personal, not an athlete comparison.
9. Open Methodology and show source labels, excluded data policy, and state counts.
10. Show the code or environment proving `gemini-3.1-pro-preview` usage.

Common Ground turns public data into safe, inclusive, geography-based fan discovery.
