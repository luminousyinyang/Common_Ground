# Compliance Checklist

Before submission, verify:

- [ ] No athlete names are displayed.
- [ ] No athlete images, likenesses, profile links, biographies, or individual cards are displayed.
- [ ] No Olympic rings, Paralympic Agitos, torch imagery, Team USA logos, LA28 logos, NGB logos, or third-party brand logos are used.
- [ ] No finish times, exact competition scores, rankings, medals, or athlete comparisons are shown.
- [ ] Games references use approved names: Olympic Games Paris 2024, Paralympic Games Paris 2024, Olympic Winter Games Milano Cortina 2026, Paralympic Winter Games Milano Cortina 2026, and LA28 Games / LA28 Olympic and Paralympic Games if LA28 is referenced.
- [ ] Sport names use sport terminology rather than NGB or sponsor names.
- [ ] Olympic and Paralympic panels are always displayed together.
- [ ] There is no "Switch to Paralympic View" control.
- [ ] Geography wording remains conditional and does not imply terrain or climate guarantees results.
- [ ] Mini-game results are personal fan-game results only.
- [ ] Gemini keys are server-side only.
- [ ] Gemini output has local compliance validation and fallback copy.
- [ ] Public repo uses Apache License 2.0.
- [ ] README and docs explain source coverage and aggregation policy.
